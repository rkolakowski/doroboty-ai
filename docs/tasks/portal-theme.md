# Portal-wide cobalt and lime theme

Extend the project-level DESIGN.md from the application record to the whole local portal. Use a single palette for public listings and offers, account selection, candidate, employer and operator screens. Preserve navigation, responsive components and role workflows.

Host tokens own cobalt actions, pale separators, cool background, white surfaces, graphite text and system-ui typography. Lime is reserved for prominent callouts. Status, warning and match-score colors retain their meaning. Marketplace styles draw from the same host tokens. The reference illustration is displayed in grayscale as a portal adaptation.

Acceptance includes theme consistency and horizontal fit on public and signed-in routes on desktop and mobile, readable action and hover colors, and normal access to application status and deadlines.
